# 🔔 Функция "Вызов официанта" через Telegram

## Описание
На сайте кафе реализована функция вызова официанта через Telegram-бота. Кнопка появляется только при наличии параметра `table` в URL и отправляет сообщение в Telegram группу персонала.

## Как использовать

### 1. QR-коды для столиков
Каждому столику должен соответствовать свой QR-код, ведущий на:
```
https://вашдомен.com/index.html?table=НОМЕР_СТОЛА
```

Примеры:
- Столик 1: `?table=1`
- Столик 3: `?table=3`
- Столик 15: `?table=15`

### 2. Логика работы

**При клике на кнопку "🔔 Позвать официанта":**
1. ✅ Кнопка блокируется (становится недоступна)
2. 📤 Отправляется POST-запрос к Telegram Bot API
3. 📬 Сообщение вида "🔔 Столик №3 просит официанта" появляется в группе персонала
4. ⏱️ Кнопка блокируется на 15 секунд с текстом "✅ Официант уже идёт"
5. 🔄 После блокировки кнопка становится активной снова

**При ошибке сети:**
- Показывается текст "❌ Ошибка, попробуйте ещё раз"
- Кнопка остаётся активной для повторной попытки

## Технические детали

### Токен Telegram бота
Находится в [script.js](script.js) (строка ~366):
```javascript
const TELEGRAM_BOT_TOKEN = "8900105881:AAGZLy7-sB_z7-tAzHdIACPCwUpXvLXhubY";
```

### Chat ID группы персонала
Находится в [script.js](script.js) (строка ~367):
```javascript
const TELEGRAM_CHAT_ID = "-1004410311353";
```

⚠️ **ВАЖНО:** Для использования в production среде замените эти значения своими!

### Как получить свои credentials:

1. **Создать Telegram бота:**
   - Напишите @BotFather в Telegram
   - Команда `/newbot` 
   - Получите TOKEN

2. **Получить Chat ID группы:**
   - Создайте приватную группу в Telegram
   - Добавьте вашего бота в группу
   - Отправьте сообщение: `/start`
   - Используйте API для получения Chat ID

## Стилизация

Кнопка соответствует общему дизайну сайта:
- **Цвет:** Синий градиент `#3561C0 → #4A7BE0`
- **Позиция:** Левый нижний угол экрана (фиксированная позиция)
- **На мобильных:** Кнопка автоматически переходит на меньший размер
- **CSS класс:** `.call-waiter-btn`

## Визуальные состояния

1. **Нормальное состояние:** "🔔 Позвать официанта" (активная кнопка)
2. **При отправке:** "Отправляем..." (блокирована, уменьшенная прозрачность)
3. **Успех:** "✅ Официант уже идёт" (блокирована на 15 сек)
4. **Ошибка:** "❌ Ошибка, попробуйте ещё раз" (активна для повтора)

## API Интеграция

Функция использует прямой POST-запрос к Telegram Bot API:
```
POST https://api.telegram.org/bot<TOKEN>/sendMessage
Content-Type: application/json

{
  "chat_id": "-1004410311353",
  "text": "🔔 Столик №3 просит официанта"
}
```

Нет серверной части — всё работает на клиенте с помощью fetch API.

## Безопасность

⚠️ **Примечание:** Токен бота хранится в клиентском JS-коде, что делает его видимым в исходном коде страницы. Это приемлемо только если:
- Бот используется исключительно для отправки сообщений
- У группы персонала закрыт доступ
- Нет критичных данных в этом боте

Для более высокого уровня безопасности используйте backend для отправки сообщений.
