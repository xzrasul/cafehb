# 🔔 Функция "Вызов официанта" через Telegram

**Статус:** ✅ Полностью интегрирована и работает

## 📋 Краткое описание

На сайте кафе реализована система вызова официанта через Telegram без серверной части. Каждому столику соответствует QR-код с параметром `?table=X`. При сканировании QR-кода гость видит кнопку "🔔 Позвать официанта", которая отправляет сообщение в Telegram группу персонала.

### ⚡ Как это работает:

```
QR-код (table=3)
    ↓
Открывается сайт с ?table=3
    ↓
На странице видна кнопка "🔔 Позвать официанта"
    ↓
Гость нажимает кнопку
    ↓
Сообщение отправляется в Telegram:
"🔔 Столик №3 просит официанта"
    ↓
Официант видит уведомление в Telegram
```

## 🚀 Быстрый старт

### 1. Проверьте работу локально:

```bash
# Откройте в браузере:
file:///path/to/cafehb/index.html?table=3

# Нажмите на кнопку и проверьте что сообщение пришло в Telegram
```

### 2. Для production:

1. Замените значения в `script.js` (строки 366-367):
   ```javascript
   const TELEGRAM_BOT_TOKEN = "ВАШ_ТОКЕН_СЮДА";
   const TELEGRAM_CHAT_ID = "ВАШ_CHAT_ID_СЮДА";
   ```

2. Создайте QR-коды для каждого стола (см. [QR_CODES_SETUP.md](QR_CODES_SETUP.md))

3. Разместите QR-коды на столиках

## 🌐 API интеграция

Функция использует прямой запрос к Telegram Bot API:

```
POST https://api.telegram.org/bot<TOKEN>/sendMessage
Content-Type: application/json

{
  "chat_id": "<CHAT_ID>",
  "text": "🔔 Столик №3 просит официанта"
}
```

## 🔐 Безопасность

⚠️ **Важно:** Токен бота хранится в клиентском JS-коде и видим в исходнике.

Это безопасно, если:
- ✅ Бот используется только для отправки сообщений
- ✅ Нет чувствительных операций через этот бот
- ✅ Группа персонала закрыта от посторонних
