## 🎯 Как работает система

### Пошаговый процесс:

```
1️⃣  Гость нажимает "🔔 Позвать официанта"
         ↓
2️⃣  Кнопка показывает "Отправляем..."
         ↓
3️⃣  Сообщение отправляется в Telegram
         ↓
4️⃣  Кнопка показывает "✅ Официант уже идёт"
         ↓
5️⃣  Через 3 секунды появляется форма оценки
    "Как вас обслужили?"
         ↓
6️⃣  Гость выбирает оценку (1-5 звёзд)
    • Звёзды подсвечиваются при клике
    • Работает эффект при наведении
         ↓
7️⃣  Гость нажимает "Отправить оценку"
         ↓
8️⃣  Оценка отправляется в Telegram
    Сообщение: "⭐4 Столик №3 оценил: ⭐⭐⭐⭐"
         ↓
9️⃣  Кнопка показывает "✅ Спасибо за оценку!"
         ↓
🔟 Форма закрывается через 2 секунды
         ↓
1️⃣1️⃣ Кнопка возвращается в исходное состояние
    "🔔 Позвать официанта"
```

## 🎨 Визуальные эффекты

### Звёзды:

**Не выбранные (серые):**
```
⭐ ⭐ ⭐ ⭐ ⭐
(полупрозрачные)
```

**При наведении:**
```
Звёзды становятся ярче и немного увеличиваются
⭐ ⭐ ⭐ ⭐ ⭐ (при наведении на 3-ю)
```

**После клика (выбранные, жёлтые):**
```
⭐⭐⭐⭐ ○  (выбрано 4 звезды)
(яркие жёлтые звёзды)
```

### Анимации:

- 🔔 **Появление формы:** плавный слайд вверх с увеличением масштаба
- ⭐ **Клик на звезду:** анимация "pop-in" (звезда пульсирует)
- 📤 **Отправка:** кнопка меняет текст и становится недоступной
- ✅ **Успех:** форма закрывается с плавной анимацией

## 🎮 Как взаимодействует пользователь

### Взаимодействие со звёздами:

1. **Наведение курсора на звезду:**
   - Звёзды до текущей подсвечиваются
   - Звёзды увеличиваются
   - Звёзды становятся ярче

2. **Уход курсора из области звёзд:**
   - Подсветка вернётся к выбранному состоянию
   - Размер вернётся к нормальному

3. **Клик на звезду:**
   - Звёзды до текущей остаются подсвечены
   - Срабатывает анимация "pop-in"
   - Выбранное значение сохраняется

### Отправка формы:

1. **Нажатие на "Отправить оценку":**
   - Кнопка становится недоступна
   - Текст меняется на "Отправляем..."

2. **Если не выбрана оценка:**
   - ПоказываетсяAlert "Пожалуйста, выберите оценку"

3. **После отправки:**
   - Кнопка показывает "✅ Спасибо за оценку!"
   - Оценка отправляется в Telegram
   - Оценка сохраняется в localStorage
   - Форма закрывается через 2 секунды
   - Кнопка вызова восстанавливается

## 🔒 Закрытие формы

Форма может быть закрыта тремя способами:

### 1. Клик на кнопку X (закрытие):
```javascript
closeBtn.addEventListener("click", hideRatingForm);
```

### 2. Клик на затемнённый фон:
```javascript
overlay.addEventListener("click", (e) => {
  if (e.target === overlay) hideRatingForm();
});
```

### 3. Нажатие клавиши Escape:
```javascript
document.addEventListener("keydown", (e) => {
  if (e.key === "Escape" && overlay.classList.contains("active")) {
    hideRatingForm();
  }
});
```

## 🚀 Как использовать

### Для гостя:

1. Отсканировать QR-код на столике
2. Нажать "🔔 Позвать официанта"
3. Дождаться появления формы оценки
4. Выбрать оценку (кликнуть на звезду)
5. Нажать "Отправить оценку"
