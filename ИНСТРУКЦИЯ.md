# 📋 ИНСТРУКЦИЯ: Telegram бот + Google Sheets для cafe hb

## Что получим в итоге
- Пишешь боту в Telegram → добавляешь/удаляешь товары
- Сайт читает данные прямо из Google Таблицы
- Всё бесплатно, ничего не устанавливать

---

## ШАГ 1 — Создать Telegram бота (2 минуты)

1. Открой Telegram → найди **@BotFather**
2. Напиши `/newbot`
3. Придумай имя: например `Cafe HB Menu`
4. Придумай username: например `cafehb_menu_bot`
5. BotFather пришлёт **токен** вида: `7123456789:AAFxxx...`
   → **Скопируй и сохрани его**

6. Узнай свой Telegram ID:
   → Напиши боту **@userinfobot** → он ответит твой ID (число)
   → **Скопируй и сохрани**

---

## ШАГ 2 — Создать Google Таблицу (1 минута)

1. Открой [sheets.google.com](https://sheets.google.com)
2. Создай новую таблицу
3. Назови её `cafehb-menu` (любое название)
4. Скопируй **ID** из URL:
   ```
   https://docs.google.com/spreadsheets/d/ВОТ_ЭТО_И_ЕСТЬ_ID/edit
   ```
   → **Сохрани ID**

5. **Опубликуй таблицу** для чтения:
   - Файл → Поделиться → Опубликовать в интернете
   - Выбери: весь документ → CSV
   - Нажми **Опубликовать**
   - Закрой окно

---

## ШАГ 3 — Создать бота в Google Apps Script (5 минут)

1. Открой [script.google.com](https://script.google.com)
2. Нажми **Новый проект**
3. Удали весь код в редакторе
4. Вставь код из файла `bot_google_apps_script.js`
5. Заполни в начале файла:
   ```javascript
   const BOT_TOKEN = "7123456789:AAFxxx...";  // твой токен от BotFather
   const SHEET_ID  = "1BxiMVs0XRA5...";       // ID твоей таблицы
   const ADMIN_ID  = 123456789;                // твой Telegram ID (число)
   ```
6. Нажми **💾 Сохранить** (Ctrl+S)

---

## ШАГ 4 — Задеплоить скрипт (3 минуты)

1. Нажми **Развернуть** → **Новое развертывание**
2. Тип: **Веб-приложение**
3. Настройки:
   - Описание: `cafehb bot`
   - Выполнять от имени: **Меня**
   - Кто имеет доступ: **Все**
4. Нажми **Развернуть**
5. Разреши доступ (нажми "Разрешить")
6. Скопируй **URL веб-приложения** → выглядит так:
   ```
   https://script.google.com/macros/s/AKfycbxxx.../exec
   ```
   → **Сохрани URL**

---

## ШАГ 5 — Подключить webhook (1 минута)

1. В редакторе Apps Script найди функцию `setWebhook`
2. Вставь URL из шага 4:
   ```javascript
   const WEBHOOK_URL = "https://script.google.com/macros/s/AKfycbxxx.../exec";
   ```
3. Сохрани файл
4. Выбери функцию `setWebhook` в выпадающем списке (вверху редактора)
5. Нажми **▶ Запустить**
6. В логах должно быть: `{"ok":true,"result":true,...}`

---

## ШАГ 6 — Обновить сайт (2 минуты)

1. Замени файл `products.js` на новый (из папки)
2. В новом `products.js` вставь ID таблицы:
   ```javascript
   const SHEET_ID = "1BxiMVs0XRA5..."; // твой ID из шага 2
   ```
3. Загрузи на GitHub/Netlify/Vercel

> ⚠️ В `index.html` убери строки с Firebase (они больше не нужны):
> ```html
> <!-- УДАЛИ ЭТИ 4 СТРОКИ -->
> <script src="https://www.gstatic.com/firebasejs/...firebase-app-compat.js"></script>
> <script src="https://www.gstatic.com/firebasejs/...firebase-firestore-compat.js"></script>
> <script src="firebase-config.js"></script>
> <script>if (typeof firebase !== 'undefined') firebase.initializeApp(firebaseConfig);</script>
> ```

## Как пользоваться ботом

| Команда   | Что делает                        |
|-----------|-----------------------------------|
| `/start`  | Главное меню                      |
| `/add`    | Добавить товар (фото + название + цена) |
| `/list`   | Посмотреть все товары             |
| `/delete` | Удалить товар                     |
| `/cancel` | Отменить текущее действие         |

### Добавить товар — пример диалога:
```
Ты:  /add
Бот: Выбери категорию [кнопки]
Ты:  [нажимаешь "🍔 Бургеры"]
Бот: Отправь фото товара
Ты:  [отправляешь фото]
Бот: Напиши название
Ты:  Двойной чизбургер
Бот: Напиши цену
Ты:  45
Бот: Проверь: Бургеры / Двойной чизбургер / 45c — сохранить?
Ты:  [нажимаешь ✅]
Бот: Товар сохранён! Сайт обновится автоматически.
```

---

## Если что-то не работает

**Бот не отвечает** → проверь что webhook установлен (шаг 5)

**Сайт не показывает товары** → проверь что таблица опубликована (шаг 2, пункт 5)

**Ошибка прав** → при деплое убедись что выбрал "Кто имеет доступ: Все"

**После изменений в коде** → нужно делать **новое развертывание** и обновлять webhook URL
